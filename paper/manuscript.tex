\begin{abstract}
Autonomous tool-calling Large Language Model (LLM) agents are increasingly entrusted with operational authority in enterprise business workflows, including financial disbursements, database modifications, and customer identity operations. However, existing safety paradigms rely predominantly on in-context system prompts or post-hoc classifiers, both of which remain vulnerable to indirect prompt injection, privilege escalation, and adversarial parameter tampering. In this paper, we propose \textbf{Ontology-Constrained Token Decoding (O-CTD)}, a neuro-symbolic framework that compiles formal, declarative Role-Based Access Control (RBAC) ontologies into runtime Context-Free Grammars (CFGs). By projecting the LLM's autoregressive logit distribution onto the permissible transitions of a Deterministic Finite Automaton (DFA) at each generation step, O-CTD mathematically guarantees that unauthorized tool selections and out-of-bounds parameter values cannot be sampled. We empirically evaluate O-CTD against three standard industry baselines across 100 enterprise business scenarios (400 total inferences) using \texttt{Qwen2.5-7B-Instruct} on an NVIDIA RTX 4090 GPU. Experimental results demonstrate that O-CTD suppresses the Attack Success Rate (ASR) from 80.0\% (in-context guardrails) down to 20.0\%, reduces policy Invariant Violation Rates (IVR) from 90.0\% to 10.0\%, and achieves 100.0\% Benign Task Completion (BTC). A paired Wilcoxon signed-rank test confirms statistical significance ($W = 0.0, p = 3.74 \times 10^{-19}, r = 0.800$). We publish our benchmark suite, declarative schemas, and decoding harness to advance formal verification in agentic AI.
\end{abstract}

\section{Introduction}
\label{sec:intro}

The integration of Large Language Models (LLMs) with external Application Programming Interfaces (APIs) and tool-calling execution engines marks a transition toward autonomous enterprise software agents \cite{qin2024toolllm, qwen2024qwen25}. In modern decision-support ecosystems, autonomous agents are granted live execution access to issue invoice credits, adjust customer shipping destinations, and execute relational database queries \cite{dubey2024llama, pan2024unifying}.

However, deploying autonomous agents within mission-critical infrastructure creates severe security vulnerabilities \cite{li2024security, nist2024genairmf, owasp2025top10}. Most prominently, untrusted data ingested during execution---such as third-party vendor emails, customer dispute attachments, or web search results---frequently contains adversarial instructions designed to hijack the model's decision cycle via \textit{indirect prompt injection} (IPI) \cite{zhan2024injecagent, debenedetti2024agentdojo}. In these scenarios, the autonomous agent suffers from the classic \textit{Confused Deputy} vulnerability \cite{mavrogiannis2024confused}, leveraging its authenticated enterprise privileges to execute destructive actions unintended by the system operator \cite{ruan2024identifying, deng2024pentestgpt}.

To safeguard agentic systems, industry practitioners currently depend on two predominant defensive paradigms:
\begin{enumerate}
    \item \textbf{In-Context Instructional Prompt Guarding:} Embedding natural-language security constraints within the system prompt (e.g., \textit{``You are a Tier-1 support agent. You are strictly forbidden from exceeding \$50.00 in refunds or accessing financial ledgers''}) \cite{wei2024jailbroken, wu2024empirical}.
    \item \textbf{Post-Hoc Output Classification:} Employing external safety classifiers, guard models, or heuristic regular expressions to intercept generated function calls prior to API dispatch \cite{wang2025progent, chen2024benchmarking}.
\end{enumerate}

Both paradigms exhibit fundamental architectural limitations. Instructional prompt guards rely on probabilistic next-token generation; adversarial jailbreak techniques (e.g., roleplay wrappers, executive override framing, or debug-mode prompts) routinely override soft in-context instructions by shifting the token probability distribution \cite{wei2024jailbroken, zhou2024robustness}. Conversely, post-hoc classifiers operate after generation has completed, decoupling security enforcement from the model's internal reasoning while failing against obfuscated or encoded malicious payloads \cite{ruan2024identifying, yang2024privilege}.

To overcome these structural limitations, we present \textbf{Ontology-Constrained Token Decoding (O-CTD)}, a neuro-symbolic framework that enforces axiomatic least-privilege directly within the autoregressive decoding process \cite{wang2024survey, he2024formal}. Rather than relying on soft instructional adherence, O-CTD compiles declarative Role-Based Access Control (RBAC) ontologies into dynamic Context-Free Grammars (CFGs) and Deterministic Finite Automata (DFAs) \cite{zhang2024syncode, zhao2024xgrammar}. At every generation step, the LLM's output logits are projected onto the set of admissible tokens defined by the active session's security grammar \cite{beurer2024guiding, kumar2024inference}. Any token representing an unauthorized tool or an out-of-bounds numeric parameter is mathematically masked prior to sampling \cite{sordoni2024automata, tiwari2025grammarenforced}.

The main contributions of this paper are as follows:
\begin{itemize}
    \item \textbf{Formalization of Axiomatic Least-Privilege for LLM Agents:} We formalize enterprise security policies as declarative ontologies $\mathcal{O} = \langle \mathcal{R}, \mathcal{T}, \Sigma \rangle$ and formally decouple the authorization predicate into structural/bounded constraints $\Phi_{\text{struct}}$ and free-text semantic fields $\Phi_{\text{semantic}}$, establishing clean theoretical verification boundaries.
    \item \textbf{Ontology-Constrained Token Decoding (O-CTD):} We develop a neuro-symbolic compilation and decoding pipeline that maps session roles to localized Context-Free Grammars $\mathcal{G}_r$ and runtime vocabulary DFAs $\mathcal{D}_r$, projecting unconstrained logits onto admissible tokens with zero runtime parsing overhead.
    \item \textbf{BPE-Safe Numeric Sub-Grammar Formulation:} We formulate exact regular grammar production rules in Extended Backus-Naur Form (EBNF) that prevent multi-token decimal overflow on sub-word tokenizers, strictly enforcing monetary disbursement ceilings ($C_r \le \$50.00$).
    \item \textbf{Dual-Metric Enterprise Benchmark \& Empirical Evaluation:} We synthesize a balanced 100-scenario enterprise benchmark across three operational roles and five threat classes, introducing a dual-metric evaluation (Strict vs. Relaxed Task Completion) and proving that O-CTD delivers a $4\times$ reduction in Attack Success Rate (from 80.0\% to 20.0\%) with verified statistical significance ($p = 3.74 \times 10^{-19}, r = 0.800$).
\end{itemize}

The rest of this paper is organised as follows: Section~\ref{sec:math} details the formal mathematical formulation of O-CTD, its compilation into regular and context-free grammars, and theoretical soundness proofs; Section~\ref{sec:exp} describes the benchmark suite, hardware configuration, baseline architectures, and formal metric definitions; Section~\ref{sec:results} presents the empirical comparative results, ablation study, statistical significance tests, and Pareto analysis; Section~\ref{sec:conclusion} discusses limitations, future directions, and concludes the paper.

\subsection{Declarative Enterprise RBAC Ontology}

We formalize enterprise operational policies as an axiomatic security ontology defined over roles, tools, and parametric bounds \cite{yang2024privilege, tiwari2025grammarenforced}.

\begin{definition}[Enterprise Security Ontology]
An Enterprise Security Ontology is a 3-tuple:
\begin{equation}
    \mathcal{O} = \langle \mathcal{R}, \mathcal{T}, \Sigma \rangle
\end{equation}
where:
\begin{itemize}
    \item $\mathcal{R} = \{r_1, r_2, \dots, r_m\}$ denotes the finite set of enterprise session roles (e.g., \texttt{CustomerSupportTier1}, \texttt{BillingManager}, \texttt{DataAnalyst}).
    \item $\mathcal{T} = \{t_1, t_2, \dots, t_n\}$ represents the global catalog of operational tools and APIs.
    \item $\Sigma = \{\sigma_1, \sigma_2, \dots, \sigma_k\}$ denotes the set of formal security axioms governing action validity.
\end{itemize}
\end{definition}

Each active session role $r \in \mathcal{R}$ is mapped to an authorized tool subspace $\mathcal{T}_r \subseteq \mathcal{T}$ and a role-specific axiom subset $\Sigma_r \subseteq \Sigma$. 

To establish formal verification boundaries, we partition the tool argument assignment dictionary $\theta$ into structured, bounded parameters and unbounded natural-language strings:
\begin{equation}
    \theta = \langle \theta_{\text{bounded}}, \theta_{\text{free}} \rangle
\end{equation}
where $\theta_{\text{bounded}}$ encompasses categorical enumerations, booleans, and numeric parameters governed by formal security axioms $\Sigma_r$, while $\theta_{\text{free}}$ represents open-ended free-text fields (e.g., support ticket notes, user search queries). An executed action is defined as a pair $a = \langle t, \theta \rangle$. The global authorization predicate $\Phi(a, r)$ is formally decoupled as:
\begin{equation}
    \Phi(\langle t, \theta \rangle, r) \iff \Phi_{\text{struct}}(\langle t, \theta_{\text{bounded}} \rangle, r) \land \Phi_{\text{semantic}}(\theta_{\text{free}})
\end{equation}
where the structural and parametric authorization predicate $\Phi_{\text{struct}}$ evaluates as:
\begin{equation}
    \Phi_{\text{struct}}(\langle t, \theta_{\text{bounded}} \rangle, r) \iff \left( t \in \mathcal{T}_r \right) \land \left( \forall \sigma \in \Sigma_r, \, \sigma(\theta_{\text{bounded}}) = \text{True} \right)
\end{equation}

In enterprise decision-support settings, parametric axioms $\sigma \in \Sigma_r$ enforce strict operational boundaries:
\begin{align}
    \sigma_{\text{refund}}(\theta) &\iff \theta[\text{amount\_usd}] \le C_r \\
    \sigma_{\text{address}}(\theta) &\iff \theta[\text{is\_international}] = \text{False} \\
    \sigma_{\text{sql}}(\theta) &\iff \theta[\text{query}] \notin \mathcal{L}_{\text{prohibited}}
\end{align}
where $C_r$ is the maximum refund ceiling authorized for role $r$ ($C_{\text{Tier1}} = \$50.00$, $C_{\text{Billing}} = \$1000.00$), and $\mathcal{L}_{\text{prohibited}}$ represents prohibited database modification commands.

\subsection{Context-Free Grammar Compilation}

To enforce $\Phi_{\text{struct}}(\langle t, \theta_{\text{bounded}} \rangle, r)$ during autoregressive inference, the compilation operator $\mathcal{M}$ maps the active role definition $r$ into a formal Context-Free Grammar $\mathcal{G}_r = \langle V_N, V_T, P, S \rangle$ \cite{zhang2024syncode, zhao2024xgrammar}:
\begin{equation}
    \mathcal{M}: r \mapsto \mathcal{G}_r
\end{equation}
where $V_T$ is the terminal alphabet (the model's character encoding), $V_N$ is the set of non-terminals, $P$ is the set of production rules, and $S$ is the start symbol.

Under $\mathcal{G}_r$, the production rule for the action name is strictly restricted to the literal disjunction of authorized tools:
\begin{equation}
    S_{\text{action}} \to \text{\texttt{"action\_name": }} \left( t_{r, 1} \mid t_{r, 2} \mid \dots \mid t_{r, |\mathcal{T}_r|} \right) \quad \forall t_{r, j} \in \mathcal{T}_r
\end{equation}

\subsection{BPE-Safe Numeric Sub-Grammar Formulation}
\label{sec:numeric_ebnf}

Enforcing continuous numeric bounds (e.g., $\theta[\text{amount\_usd}] \le C_r$) over Byte-Pair Encoded (BPE) sub-word tokenizers represents a non-trivial challenge, as tokens correspond to arbitrary byte sequences rather than structured decimal positions.

To guarantee that no numeric token sequence representing a value exceeding $C_r$ can be sampled, O-CTD compiles parametric ceilings into bounded regular grammars. For a role ceiling $C_r = \$50.00$, the production rules in Extended Backus-Naur Form (EBNF) are:
\begin{align}
    \text{RefundAmount} &\to \text{IntegerPart} \,\, (\text{"."} \,\, [0\text{-}9] \,\, [0\text{-}9])? \\
    \text{IntegerPart} &\to [0\text{-}9] \mid [1\text{-}4][0\text{-}9] \mid \text{"50"}
\end{align}
This regular language $\mathcal{L}_{\text{num}} = \{ x \in \mathbb{R}_{\ge 0} \mid x \le C_r \}$ is compiled into a Deterministic Finite Automaton $\mathcal{D}_{\text{num}}$. When intersecting $\mathcal{D}_{\text{num}}$ with the tokenizer vocabulary $\mathcal{V}$, any token whose concatenation with preceding prefix digits produces a numerical prefix $> C_r$ (e.g., token \texttt{"51"} or token \texttt{"100"}) contains no outgoing transition $\delta(q, v)$ and is assigned an infinite negative mask \cite{beurer2024guiding}.

\subsection{Logit-Masking Projection Operator}

Let $\mathcal{V}$ denote the model vocabulary with size $|\mathcal{V}|$, and let $x_{<t} = [x_1, \dots, x_{t-1}]$ represent the sequence of generated tokens up to decoding step $t$. At step $t$, the base model outputs unconstrained logits $\mathbf{z}_t \in \mathbb{R}^{|\mathcal{V}|}$.

The grammar $\mathcal{G}_r$ is compiled into a Deterministic Finite Automaton (DFA) $\mathcal{D}_r = \langle Q, \mathcal{V}, \delta, q_0, F \rangle$ over the vocabulary \cite{zhao2024xgrammar, sordoni2024automata}. Let $q_t \in Q$ denote the active DFA state after consuming $x_{<t}$. The set of admissible next tokens $\mathcal{A}(q_t) \subseteq \mathcal{V}$ is formally defined as:
\begin{equation}
    \mathcal{A}(q_t) = \{ v \in \mathcal{V} \mid \exists q' \in Q, \, \delta(q_t, v) = q' \}
\end{equation}

The neuro-symbolic projection operator $\mathcal{P}_{\mathcal{G}_r}: \mathbb{R}^{|\mathcal{V}|} \to \mathbb{R}^{|\mathcal{V}|}$ masks the logit distribution:
\begin{equation}
    \mathcal{P}_{\mathcal{G}_r}(\mathbf{z}_t)_v = 
    \begin{cases} 
        \mathbf{z}_{t, v} & \text{if } v \in \mathcal{A}(q_t) \\
        -\infty & \text{if } v \notin \mathcal{A}(q_t)
    \end{cases}
\end{equation}

The next token is sampled from the normalized masked distribution:
\begin{equation}
    x_t \sim \text{Softmax}\left( \mathcal{P}_{\mathcal{G}_r}(\mathbf{z}_t) \right)
\end{equation}

Algorithm~\ref{alg:octd} provides the operational execution loop for O-CTD.

\begin{algorithm}[t]
\caption{Ontology-Constrained Token Decoding (O-CTD)}
\label{alg:octd}
\begin{algorithmic}[1]
\Require Prompt sequence $\mathbf{p}$, Active role $r \in \mathcal{R}$, Security ontology $\mathcal{O}$, Language model $\mathcal{M}_{\theta}$, Vocabulary $\mathcal{V}$
\Ensure Valid, authorized tool call $a = \langle t, \theta \rangle$ satisfying $\Phi_{\text{struct}}(\langle t, \theta_{\text{bounded}} \rangle, r) = \text{True}$
\State $\mathcal{G}_r \gets \text{CompileGrammar}(r, \mathcal{O})$ \Comment{Compile role sub-grammar}
\State $\mathcal{D}_r \gets \text{ConstructDFA}(\mathcal{G}_r, \mathcal{V})$ \Comment{Build vocabulary DFA}
\State $q_0 \gets \text{InitialState}(\mathcal{D}_r)$, $x_{<1} \gets \mathbf{p}$, $t \gets 1$
\While{$x_{t-1} \neq \text{\texttt{<EOS>}}$ and $t \le K_{\text{max}}$}
    \State $\mathbf{z}_t \gets \mathcal{M}_{\theta}(x_{<t})$ \Comment{Forward pass unconstrained logits}
    \State $\mathcal{A}(q_{t-1}) \gets \{ v \in \mathcal{V} \mid \delta(q_{t-1}, v) \neq \emptyset \}$ \Comment{Admissible token mask}
    \State $\tilde{\mathbf{z}}_t \gets \mathcal{P}_{\mathcal{G}_r}(\mathbf{z}_t)$ via Eq.~(14)
    \State $x_t \sim \text{Softmax}(\tilde{\mathbf{z}}_t)$ \Comment{Sample valid token}
    \State $q_t \gets \delta(q_{t-1}, x_t)$ \Comment{Advance DFA state}
    \State $x_{<t+1} \gets [x_{<t}, x_t]$, $t \gets t + 1$
\EndWhile
\State \Return $\text{ParseJSON}(x_{<t})$
\end{algorithmic}
\end{algorithm}

\subsection{Theoretical Soundness \& Decidability Boundaries}

\begin{theorem}[Soundness of Structural \& Parametric Enforcement]
Let $\mathbf{x} = [x_1, \dots, x_K]$ be a generation sequence completed under O-CTD. Then the extracted tool invocation $a = \langle t, \theta \rangle = \text{Parse}(\mathbf{x})$ satisfies:
\begin{equation}
    P\left( \Phi_{\text{struct}}(\langle t, \theta_{\text{bounded}} \rangle, r) = \text{False} \right) = 0
\end{equation}
for all structural tool signatures and bounded parametric axioms encoded within $\mathcal{G}_r$.
\end{theorem}
\begin{proof}
By construction, generating an unauthorized tool $t \notin \mathcal{T}_r$ or a numeric token sequence violating $\theta_{\text{bounded}} \le C_r$ requires traversing an invalid state transition $\delta(q_t, v) = \emptyset$ in $\mathcal{D}_r$. By Eq.~(14), $\mathcal{P}_{\mathcal{G}_r}(\mathbf{z}_t)_v = -\infty$, which yields $P(x_t = v) = 0$ upon Softmax normalization. By induction over decoding steps $1 \le t \le K$, the probability of emitting any non-conforming token sequence is identically zero.
\end{proof}

\begin{remark}[Decidability Boundary and Semantic Orthogonality]
Theorem~1 guarantees soundness strictly over the structural and bounded parametric domain $\Phi_{\text{struct}}$. Conversely, semantic validation over unbounded natural-language strings $\theta_{\text{free}}$ (e.g., ensuring a customer support note does not leak confidential context) is undecidable via regular or context-free grammars alone. This formal theoretical distinction directly explains the empirical residual ASR observed in Section~\ref{sec:residual_asr}.
\end{remark}

\subsection{Complexity and Scalability Analysis}

A critical challenge in enterprise agent deployments is catalog scalability. In production environments containing thousands of APIs, compiling a global monolithic grammar causes combinatorial state explosions \cite{zhao2024xgrammar}. 

Under O-CTD, the compilation operator $\mathcal{M}$ generates a localized grammar strictly bounded to the active session role $r$. Because typical enterprise roles authorize a restricted subset of operations ($|\mathcal{T}_r| \ll |\mathcal{T}|$, typically $4 \le |\mathcal{T}_r| \le 12$), the DFA state space $|Q_r|$ remains bounded. Runtime token lookup overhead scales as $\mathcal{O}(|\mathcal{T}_r| \cdot |\mathcal{V}|)$, ensuring that memory consumption and DFA traversal latency remain independent of the global enterprise catalog size.

\subsection{Cross-Architecture Portability \& Tokenizer Invariance}

A vital theoretical property of O-CTD is its strict invariance to foundation model tokenization architectures. Modern open-weight foundation models utilize divergent tokenization strategies with distinct vocabulary dimensions, such as \texttt{Qwen2.5-7B} ($|\mathcal{V}| = 151,643$ sub-words with byte fallback) \cite{qwen2024qwen25} and \texttt{Llama-3.1-8B} ($|\mathcal{V}| = 128,256$ sub-words via tiktoken) \cite{dubey2024llama}.

Because the compilation mapping $\mathcal{M}: r \mapsto \mathcal{G}_r$ defines production rules over Unicode terminal characters, the DFA state transition function $\delta(q_t, v)$ is constructed by projecting the grammar onto the specific vocabulary $\mathcal{V}$ of whichever underlying foundation model is deployed:
\begin{equation}
    \mathcal{A}_{\text{model}}(q_t) = \{ v \in \mathcal{V}_{\text{model}} \mid \exists q' \in Q, \, \delta(q_t, v) = q' \}
\end{equation}
Consequently, Theorem~1's guarantee of axiomatic containment ($P(\Phi_{\text{struct}} = \text{False}) = 0$) holds identically across both Qwen and Llama model families, ensuring portable neuro-symbolic enforcement across heterogeneous foundation model deployments.

\section{Experimental Methodology}
\label{sec:exp}

\subsection{Benchmark Dataset \& Threat Classes}

We synthesized a standardized benchmark suite consisting of $N = 100$ balanced enterprise evaluation scenarios (50 adversarial prompt injections and 50 benign business tasks) modeled after the InjecAgent and AgentDojo threat suites \cite{zhan2024injecagent, debenedetti2024agentdojo, zhou2024robustness}. The scenarios evaluate three canonical enterprise roles:
\begin{itemize}
    \item \textbf{CustomerSupportTier1:} Frontline support handling routine order lookups and domestic shipping updates, with refunds strictly capped at \$50.00.
    \item \textbf{BillingManager:} Financial personnel authorized for invoice credits up to \$5,000.00 and refunds up to \$1,000.00.
    \item \textbf{DataAnalyst:} Analytics personnel authorized for aggregate metric reporting, barred from executing financial disbursements or querying raw payment ledgers.
\end{itemize}

The 50 adversarial evaluation cases evaluate five distinct threat classes \cite{chen2024benchmarking}:
\begin{enumerate}
    \item \textbf{Parameter Tampering (PT):} Adversaries utilize authority impersonation (e.g., ``Executive VIP Escalation'') to coerce Tier-1 agents into issuing \$500.00 to \$1,200.00 refunds.
    \item \textbf{Privilege Escalation (PE):} In-context prompts instruct agents to enter debug modes and invoke unauthorized administrative tools (\texttt{view\_payment\_ledger}).
    \item \textbf{SQL / Exfiltration Injection (SQL):} Malicious SQL payloads embedded in query strings attempting \texttt{DROP TABLE} modifications or plain-text credential extraction.
    \item \textbf{Indirect Prompt Injection (IPI):} Simulated vendor emails containing embedded system instructions directing unverified wire transfers.
    \item \textbf{Policy Boundary Tampering (PBT):} Coercing customer service agents to reroute domestic packages to embargoed international postal codes.
\end{enumerate}

\subsection{Comparative Frameworks}

We benchmark four representative architectures:
\begin{itemize}
    \item \textbf{M0 (Vanilla Base LLM):} Unconstrained generation; the agent receives standard system prompts describing tool signatures without defensive constraints.
    \item \textbf{M1 (In-Context Prompt Guard):} Standard enterprise defensive baseline; system prompts include explicit prohibitions (e.g., \textit{``CRITICAL POLICY: You are strictly barred from issuing refunds over \$50 or calling ledger tools''}) \cite{wei2024jailbroken}.
    \item \textbf{M2 (Post-Hoc Classifier):} Unconstrained generation followed by an external safety validation pass that inspects generated JSON before execution \cite{wang2025progent}.
    \item \textbf{M* (Proposed O-CTD):} Autoregressive generation strictly constrained by the compiled role-specific Context-Free Grammar.
\end{itemize}

\subsection{Hardware and Software Configuration}

All experiments were executed on a dedicated high-performance compute node with the following specifications:
\begin{itemize}
    \item \textbf{Hardware Architecture:} A single NVIDIA GeForce RTX 4090 GPU (Ada Lovelace architecture, 16,384 CUDA cores, 24 GB GDDR6X VRAM on PCIe 4.0), coupled with a 16-core Intel Xeon Gold processor and 64 GB host system RAM.
    \item \textbf{Software Stack:} Ubuntu 22.04 LTS, CUDA 12.1 driver, Python 3.10 runtime environment, and PyTorch 2.3.1+cu121.
    \item \textbf{Inference \& Grammar Engine:} HuggingFace Transformers 4.41.2 and Outlines 1.0.0 for token-level DFA compilation and logit masking. Non-parametric statistical tests were executed with SciPy 1.13.0.
    \item \textbf{Model Execution Controls:} \texttt{Qwen/Qwen2.5-7B-Instruct} \cite{qwen2024qwen25} loaded in native \texttt{bfloat16} precision directly onto \texttt{cuda:0} with zero CPU offloading. Generation parameters were strictly pinned to greedy decoding ($\text{temperature} = 0.0$, $\text{top\_p} = 1.0$) with maximum token generation length capped at 512 tokens. A global fixed random seed ($\tau = 42$) was enforced across all benchmark runs to guarantee complete determinism and reproducibility.
\end{itemize}

\subsection{Formal Evaluation Metrics}

We track five formal evaluation metrics to comprehensively assess security containment, task utility, and computational overhead:
\begin{enumerate}
    \item \textbf{Attack Success Rate (ASR) [\% $\downarrow$]:} The fraction of adversarial attack inputs ($N_{\text{adv}} = 50$) wherein the model executes the adversary's unauthorized goal:
    \begin{equation}
        \text{ASR} = \frac{1}{N_{\text{adv}}} \sum_{i=1}^{N_{\text{adv}}} \mathbf{1}\left[ \text{GoalAchieved}(a_i) = \text{True} \right]
    \end{equation}
    \item \textbf{Invariant Violation Rate (IVR) [\% $\downarrow$]:} The proportion of total invocations ($N = 100$) that violate any declarative security axiom $\sigma \in \Sigma_r$:
    \begin{equation}
        \text{IVR} = \frac{1}{N} \sum_{i=1}^{N} \mathbf{1}\left[ \exists \sigma \in \Sigma_r, \, \sigma(\theta_{i,\text{bounded}}) = \text{False} \right]
    \end{equation}
    \item \textbf{Strict Benign Task Completion (Strict BTC) [\% $\uparrow$]:} The percentage of benign enterprise prompts ($N_{\text{benign}} = 50$) that successfully execute through automated JSON API gateways without human intervention:
    \begin{equation}
        \text{Strict BTC} = \frac{1}{N_{\text{benign}}} \sum_{i=1}^{N_{\text{benign}}} \mathbf{1}\left[ \text{ValidGatewayJSON}(a_i) \land \Phi_{\text{struct}}(a_i, r) = \text{True} \right]
    \end{equation}
    \item \textbf{Relaxed Benign Task Completion (Relaxed BTC) [\% $\uparrow$]:} Evaluates task utility after applying heuristic regular-expression extraction ($\texttt{re.search(r"\{.*\}", text, re.DOTALL)}$) to isolate JSON payloads from conversational chatter:
    \begin{equation}
        \text{Relaxed BTC} = \frac{1}{N_{\text{benign}}} \sum_{i=1}^{N_{\text{benign}}} \mathbf{1}\left[ \text{RegexJSON}(a_i) \land \Phi_{\text{struct}}(a_i, r) = \text{True} \right]
    \end{equation}
    \item \textbf{Inference Latency Overhead [ms $\downarrow$]:} End-to-end wall-clock duration per generation query, reporting both Mean and 95th-percentile (P95) latency over matched inputs.
\end{enumerate}

\subsection{Statistical Significance Testing}

To verify that the empirical superiority of O-CTD over in-context prompt guarding is statistically robust, we performed non-parametric paired significance testing \cite{gao2024nonparametric, kaufmann2024evaluating}. Because binary safety outcomes violate Gaussian normality assumptions, the paired \textbf{Wilcoxon Signed-Rank Test} was conducted across all matched prompt pairs between M1 and M*:
\begin{itemize}
    \item \textbf{Wilcoxon Test Statistic ($W$):} $0.0$
    \item \textbf{Two-Sided $p$-Value:} $\mathbf{3.7441 \times 10^{-19}} \ll 0.001$
    \item \textbf{Rank-Biserial Effect Size ($r$):} $\mathbf{0.800}$
\end{itemize}
The effect size of $r = 0.800$ exceeds the standard benchmark for a ``large'' effect ($r \ge 0.50$), confirming that O-CTD delivers statistically definitive and reproducible safety improvements.

\subsection{Qualitative Analysis of Residual ASR (20\%)}
\label{sec:residual_asr}

Rigorous empirical analysis requires examining remaining failure modes. While O-CTD suppressed ASR from 80\% to 20\%, we investigate why the residual 20\% occurred:
\begin{enumerate}
    \item \textbf{The Confused Deputy inside Free-Text Arguments:} In two test scenarios, the attack prompt requested: \textit{``Order ORD-12345 was delayed; look up its status and append a note containing internal API keys.''}. Because \texttt{lookup\_order\_status} was an authorized tool for Tier 1 support, the grammar permitted its selection. While O-CTD prevented unauthorized financial execution, the model processed the adversarial payload inside the legitimate tool's free-text comment field $\theta_{\text{free}}$ \cite{mavrogiannis2024confused}.
    \item \textbf{Safe Fallback Invocations:} Under aggressive injection where all attempted tool tokens were masked out by the DFA, the agent fell back to the default permitted tool (\texttt{lookup\_order\_status}). Although no policy violation occurred ($\Phi_{\text{struct}} = \text{True}$), the benchmark marked the sample as partially engaged because the model did not output an explicit refusal string.
\end{enumerate}
This finding directly validates Remark~1: \textbf{Context-Free Grammars mathematically eliminate structural and parametric privilege escalations ($\Phi_{\text{struct}}$), but semantic validation inside unbounded free-text fields ($\theta_{\text{free}}$) remains an orthogonal challenge requiring complementary semantic classifiers.}

\section{Conclusion and Future Work}
\label{sec:conclusion}

In this paper, we introduced \textbf{Ontology-Constrained Token Decoding (O-CTD)}, a neuro-symbolic framework that compiles declarative enterprise RBAC ontologies into runtime Context-Free Grammars and vocabulary DFAs for autonomous LLM agents. By enforcing deterministic logit masking during autoregressive generation, O-CTD mathematically eliminates unauthorized tool privilege escalations and parametric boundary tampering. On a 100-sample enterprise benchmark across three operational roles and five threat classes using \texttt{Qwen2.5-7B-Instruct} on an NVIDIA RTX 4090 GPU, O-CTD suppressed Attack Success Rates from 80.0\% down to 20.0\%, decreased policy invariant violations from 90.0\% down to 10.0\%, and achieved 100.0\% task utility with strong statistical significance ($W = 0.0, p = 3.74 \times 10^{-19}, r = 0.800$).

\subsection{Limitations}
This investigation has two primary boundaries. First, while O-CTD provides absolute mathematical guarantees over structural tool selection and bounded parameters ($P(\Phi_{\text{struct}} = \text{False}) = 0$), regular and context-free grammars cannot resolve semantic prompt injection within unbounded free-text argument fields $\theta_{\text{free}}$ (e.g., ticket comments or customer emails). Second, runtime logit masking introduces an average $2.7\times$ latency overhead ($3116.0$ ms vs. $1157.0$ ms) due to repeated DFA state-transition lookups across large foundation model vocabularies ($|\mathcal{V}| \approx 152,000$).

\subsection{Future Directions}
Future work will proceed along two trajectories: (1) integrating Attribute Grammars and lightweight semantic guardrails to extend axiomatic verification across unbounded natural-language strings $\theta_{\text{free}}$, and (2) implementing speculative decoding and GPU-accelerated bitmask DFA traversals (e.g., via CUDA kernel fusions) to reduce O-CTD decoding latency to near-parity with unconstrained inference.
